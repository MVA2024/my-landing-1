## ЭТАП 1 — Контент (приоритет: высокий)

Сейчас в лендинге нет реальных данных о Владимире. Добавить:

- [ ] **Фото** — настоящее фото в блок «Обо мне» (заменить placeholder)
- [ ] **Портфолио** — добавить блок с 2–3 реальными или учебными проектами
  - Название проекта, скриншот, стек, результат одной строкой
- [ ] **Отзывы** — блок с 2–3 отзывами (можно начать с «Отзыв будет после первого проекта»)
- [ ] **Уточнить числа** в Trust Strip — заменить заглушки на реальные

## ЭТАП 6 — Реальная отправка формы

Сейчас форма только показывает визуал. Варианты подключения:

- [ ] **Telegram Bot** — при отправке формы сообщение приходит в Telegram (через API бота)
- [ ] **Formspree.io** — бесплатный сервис, форма шлёт на email без бэкенда
- [ ] **EmailJS** — отправка email прямо из браузера без сервера

Рекомендация: начать с Formspree — подключается за 10 минут.
